# Arch // Struct Lab

**Architetture e Strutture sottili (AS_Lab)** is Ornella Iuorio's research group at the
[Politecnico di Milano](https://www.polimi.it/), in the
[Department of Architecture, Built Environment and Construction Engineering (dABC)](https://www.dabc.polimi.it/).

We work on architectural structures, prefabrication and digital fabrication.
